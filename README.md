# Proyecto Git Flow PHP

Este proyecto es parte de un ejercicio práctico para aprender a usar Git Flow en un entorno PHP.

## Pasos realizados:
1. Creación del repositorio y configuración inicial.
2. Configuración de Git Flow.
3. Creación de ramas de desarrollo.
4. Implementación de funcionalidades.

## Comandos utilizados:
- `git flow init`
- `git flow feature start crear-mi-archivo`
- `git add`, `git commit`, `git push`, etc.


# Creación de la funcionalidad: crear-mi-archivo

## Descripción

Se creó una nueva funcionalidad en la rama `feature/crear-mi-archivo`, donde se añadió un archivo PHP dentro de la carpeta `alumnos/`. Este archivo simplemente imprime un mensaje en pantalla.

## Pasos para la creación

1. Se ejecutó el comando `git flow feature start crear-mi-archivo` para crear una nueva rama de funcionalidad.
2. Se creó la carpeta `alumnos/` (si no existía) y se añadió un archivo PHP llamado `mi_archivo.php`.
3. Se utilizó `git add` para agregar el archivo a Git y `git commit` para confirmar los cambios.
4. Finalmente, se subieron los cambios a la rama `develop` con `git push`.
