# Proyecto Git Flow PHP

Este proyecto es parte de un ejercicio práctico para aprender a usar Git Flow en un entorno PHP.

## Pasos realizados:
1. Creación del repositorio y configuración inicial.
2. Configuración de Git Flow.
3. Creación de ramas de desarrollo.
4. Implementación de funcionalidades.

## Comandos utilizados:
- `git flow init`
- `git flow feature start crear-mi-archivo`
- `git add`, `git commit`, `git push`, etc.


## Funcionalidad creada:

Se creó una nueva rama feature con el nombre `crear-mi-archivo` utilizando Git Flow.  
Dentro de la carpeta `alumnos/`, se añadió un archivo PHP.  
Finalmente, se confirmó el cambio y se subió a la rama `develop`.


# Instrucciones de entrega

## Funcionalidad agregada:
- Se agregó un archivo `index.php` dentro de la carpeta `alumnos/`.

## Pasos realizados:
1. Se creó una nueva funcionalidad en Git Flow llamada `feature/modificar-index`.
2. Se creó el archivo `index.php` con el contenido PHP básico.
3. Se confirmaron los cambios y se subieron a la rama `develop`.
4. Se subieron los cambios a GitHub.
